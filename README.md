# Saihgupr's Add-ons Beta Repository

This repository contains beta versions of Home Assistant add-ons. These versions track the `develop` branch of their respective projects and are intended for testing and development purposes.

## Included Add-ons

- **[Home Assistant Editor](https://github.com/saihgupr/HomeAssistantEditor)**: A modern, visual automation and script editor for Home Assistant.
- **[Home Assistant Version Control](https://github.com/saihgupr/HomeAssistantVersionControl)**: version control integration for Home Assistant.
- **[Home Assistant Time Machine](https://github.com/saihgupr/HomeAssistantTimeMachine)**: Backup and restore functionality for Home Assistant configurations.
- **[Home Assistant Digest](https://github.com/saihgupr/HomeAssistantDigest)**: Daily summary and insights for your Home Assistant data.

## Installation

[![Open your Home Assistant instance and show the add-on store via My Home Assistant.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fsaihgupr%2Fha-addons-beta)

Or manually:

1. Navigate to **Settings** > **Add-ons** > **Add-on Store** in Home Assistant.
2. Click the three dots (menu) in the top right corner and select **Repositories**.
3. Add the URL of this repository: `https://github.com/saihgupr/ha-addons-beta`.
4. Click **Add**.
5. Find the add-ons in the store and install them!
